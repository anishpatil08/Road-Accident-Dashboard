# Road Accident Dashboard

This repository contains a data visualization project analyzing road accident statistics in the United Kingdom for the years 2021 and 2022. The dashboard provides insights into accident trends, casualty severity, vehicle types, weather conditions, road surfaces, and geographic distribution.

## Repository Contents
- **All Casualties Preview** – Visualization of all casualties across severity levels
- **Fatal Casualties Preview** – Dashboard focusing on fatal accident statistics
- **Serious Casualties Preview** – Dashboard focusing on serious accident statistics
- **Slight Casualties Preview** – Dashboard focusing on slight accident statistics
- **accident data.zip** – Dataset used for generating the dashboards

## Features
- Year-over-year comparison of accident and casualty figures
- Breakdown of casualties by severity (Fatal, Serious, Slight)
- Vehicle type analysis
- Weather and road surface impact
- Road type distribution
- Geographic mapping of accident locations

## Data
- Source:accident data.zip
- Years covered: From 2019 to 2022
